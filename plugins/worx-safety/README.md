# Worx Safety

Australian workplace health and safety (WHS) compliance via the [Worx Safety](https://worxsafety.com.au) platform.

## Configuration

| Variable | Description |
|---|---|
| `WORX_SAFETY_API_TOKEN` | API token from Worx Safety → Settings → API Tokens. Select required permissions and copy immediately (shown once only). |

## Required token permissions

| Permission | Used for |
|---|---|
| `user-read` | Inductees, inductions, training, documents |
| `asset-read` | Plant, equipment, vehicles |
| `sites-read` | Projects and site events |
| `documents-read` | Compliance documents |
