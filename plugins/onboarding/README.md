# Onboarding

Packaged from a MyHub workspace via the /developer Plugins page.

## What's in the box

- **Automations:** Notify Assignees on New Comment (installed as Draft — publish in the installing workspace)
- **WorkQ templates:** Employee Offboarding
- **Widgets:** Daily Briefing
- **MCP servers:** m365-calendar, m365-files, m365-mail-read

## Configuration

No configuration variables are required.
