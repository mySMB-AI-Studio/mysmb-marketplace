# Bookkeeping AP

Reads each supplier bill and enters it in Xero as a draft, so your team checks and approves bills instead of typing them in.

Packaged from a MyHub workspace via the /developer Plugins page.

## What's in the box

- **Automations:** Bookkeeping AP: Read bill emails (Outlook), Bookkeeping AP: Attach bill PDFs in Xero, Bookkeeping AP: Read bill emails (Hotmail), Bookkeeping AP: Read bill emails (Gmail), Bookkeeping AP: Find new bills in Xero (Hubdoc, Dext) (installed as Draft — publish in the installing workspace)
- **Custom tables:** AP bills (review and publish during extension setup)
- **Fields on built-in tables:** Client AP settings (10 fields) (added on install; uninstalling keeps them and their data)
- **Setup:** Bookkeeping AP setup (each person reviews their configuration and account bindings)
- **Processes:** Enter a supplier bill
- **Capabilities:** Correct and approve a bill in Xero, Create bill in Xero, Find Xero bills, Find Xero contacts, Read one Xero bill, Read Xero chart of accounts, Read Xero tax rates, Read Xero tracking categories
- **Evaluations:** Enter a supplier bill: bills already in Xero, Enter a supplier bill: controls
- **MCP servers:** xero-accounting, m365-mail-read, hotmail-mail, google-workspace-gmail
- **Skills:** 3
- **Agents:** 1

## Configuration

No configuration variables are required.
