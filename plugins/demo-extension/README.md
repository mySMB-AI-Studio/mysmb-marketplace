# Sample Demo Extension 1

A mock extension with placeholder details, used to preview how an extension listing appears in the mySMB marketplace.

## What it includes (mock)

- Listing metadata: tagline, highlights, long description and publisher
- Light and dark logos
- No agents, automations, forms or MCP servers (all sample/empty)

## Highlights

- Connects to a mock Acme Cloud workspace (no real data)
- Sample automations for daily summaries and invoice reminders
- Example form templates for client onboarding and feedback
- Zero configuration - install and explore instantly

## Configuration

No configuration variables are required. This extension does not call any external service.

Packaged from a MyHub workspace via the /developer Plugins page.
