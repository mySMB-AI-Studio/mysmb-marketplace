# Hammerjack

Packaged from a MyHub workspace via the /developer Plugins page.

## What's in the box

- **Automations:** Monthly Performance Reviews, Monthly Client Report PDF Generator (installed as Draft — publish in the installing workspace)
- **WorkQ templates:** Monthly Client Performance Review
- **Form templates:** Monthly Performance Review
- **Widgets:** Email Inbox, Daily Briefing
- **MCP servers:** m365-mail-send, m365-mail-read, m365-calendar, m365-files

## Configuration

No configuration variables are required.
