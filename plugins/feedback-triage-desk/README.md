# Feedback Triage Desk

Logs customer feedback into a Workspace table, triages each piece (category, severity), asks the manager whether it needs a follow-up, and turns follow-ups into WorkQ items. Sends a daily digest and reports follow-up activity. Works only inside Workspace — no connectors. (E2E test package, Nov 2026.)

Packaged from a MyHub workspace via the /developer Plugins page.

## What's in the box

- **Automations:** Daily feedback digest (installed as Draft — publish in the installing workspace)
- **Activity templates:** Feedback follow-up
- **Forms:** Follow-up outcome
- **Custom tables:** Customer feedback (review and publish during extension setup)
- **Setup:** Feedback Triage Desk setup (each person reviews their configuration and account bindings)
- **Pages:** Feedback desk (installed as Draft — publish in the installing workspace)
- **Processes:** Triage customer feedback
- **Evaluations:** Triage customer feedback: release gate
- **Agent views:** Overview, Setup pages
- **Reports:** Feedback follow-up activity (templates — "Use this report" copies one into the workspace)
- **Skills:** 1

## Configuration

No configuration variables are required.
