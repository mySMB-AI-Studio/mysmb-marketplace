# MYOB Reporting Studio

A specialist MYOB reporting agent with consistent HTML presentation, source mapping, and financial validation skills. Reports are live: they re-query the connected MYOB company file through `dataBindings`.

## What's in the box

- **MCP servers:** myob-accounting
- **Skills:** 48 (1 foundation + 47 reports)
  - **Financial statements:** profit-and-loss, balance-sheet, trial-balance, categories-list, budget-management, dashboard, exceptions-dashboard
  - **Ledger and banking:** general-ledger, journal-entries, categories-transactions, cash-movement, bank-activity, bank-transactions, coding, gst-summary, taxable-payments-annual-report
  - **Sales:** sales-register, customer-sales, customer-transactions, unpaid-invoices, aged-receivables, receivables-reconciliation, contacts
  - **Purchases:** purchase-register, supplier-purchases, supplier-transactions, unpaid-bills, aged-payables, payables-reconciliation
  - **Inventory:** item-list, item-sales, item-sales-analysis, items-register, stock-on-hand, reorder, inventory-value-reconciliation
  - **Jobs:** job-profit-and-loss, job-profit-and-loss-comparison, job-activity, job-transactions, job-exceptions
  - **Payroll:** payroll-summary, payroll-register, pay-item-transactions, accrual-by-fund, leave-balance, timesheets
- **Agents:** 1 (MYOB Reporting Specialist)

## Configuration

No configuration variables are required.
