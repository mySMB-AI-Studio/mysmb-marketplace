# MYOB Reporting Studio

A specialist MYOB reporting agent with consistent HTML presentation, source mapping, and financial validation skills.

**Scope note (2026-09-22):** this initial package bundles only the Wave 2 report skills — Wave 1's 15 report skills (Profit & Loss, Balance Sheet, Aged Receivables/Payables, etc., built 2026-09-15 through 09-21) are deliberately not included yet, pending confirmation that this packaged-plugin format works end-to-end for the MYOB agent. If it does, Wave 1's skills should be folded in the same way.

## What's in the box

- **MCP servers:** myob-accounting
- **Skills:** 21 (1 foundation + 20 Wave 2 reports)
- **Agents:** 1

## Configuration

No configuration variables are required.
