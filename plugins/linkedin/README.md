# LinkedIn

Access LinkedIn Marketing Solutions via the myHub-hosted LinkedIn MCP gateway. Campaign analytics — spend, impressions, clicks, and CTR across your LinkedIn ad campaigns.

## Tools & resources

### Campaign analytics
- Campaign performance metrics (spend, impressions, clicks, CTR) over a date range
- List active campaigns with per-campaign breakdown

## Widgets

- **Campaign Performance** — last-30-day spend, impressions, clicks, and CTR with a per-campaign breakdown

## Authentication

LinkedIn uses browser OAuth. Sign in with your LinkedIn account when prompted — no API keys to manage. The gateway requires a LinkedIn app with Marketing API access; contact your myHub administrator if the connector is not available.

## Configuration

No credentials to set — authentication is handled via browser OAuth sign-in.
