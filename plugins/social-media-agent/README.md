# Social Media Agent

Plans campaigns and drafts social posts, articles, emails and simple visuals in your brand's voice. Each draft is saved to a folder for its content type and booked into WorkQ with review and publish dates. It never posts or sends anything for you, and never invents prices, dates, offers or testimonials.

Packaged from a MyHub workspace via the /developer Plugins page.

## Configuration

No configuration variables are required.
