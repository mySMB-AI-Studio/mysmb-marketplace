# Xero Reporting Studio

A specialist Xero reporting agent that builds LIVE, interactive HTML reports — data bindings, refresh, organisation and period controls, filters and sorting — with consistent presentation, source mapping, and financial validation.

## What's in the box

- **MCP servers:** xero-accounting (the mySMB Xero connector). Every report reads from its tools; nothing is written back to Xero.
- **Skills:** 16 — the shared `xero-report-foundation` plus 15 report skills (Business Overview, Sales Overview, Purchases Overview, Reports Catalog, Activity Statement as a GST summary, Profit and Loss, Balance Sheet, Aged Receivables, Aged Payables, Cash Summary, Performance Overview, Cash Position, Cash Flow Manager, Business Health Scorecard, Visualise).
- **Agents:** 1 — Xero Reporting Specialist.

Datasets the connector has no endpoint for (a lodgeable BAS, Xero's Cash Summary and cash-flow statement, Xero Analytics widgets, benchmarks, bank-feed statement balances) are shown as N/A — not in source.

## Configuration

No configuration variables are required.
