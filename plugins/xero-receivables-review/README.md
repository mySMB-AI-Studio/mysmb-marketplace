# Xero Receivables Review

Reviews unpaid Xero sales invoices, identifies overdue balances and data exceptions, and prepares a report for human approval. Uses a Xero trial or demo company in QA. No payments, invoice changes or customer messages.

Packaged from a MyHub workspace via the /developer Plugins page.

## What's in the box

- **Setup:** Xero Receivables Review setup (each person reviews their configuration and account bindings)
- **Processes:** Review current Xero receivables
- **Capabilities:** List current Xero sales invoices, Read one Xero invoice, Read the connected Xero organisation
- **Evaluations:** Receivables review — coordinator controls, Receivables review — model and evidence quality
- **MCP servers:** xero-accounting
- **Skills:** 2
- **Agents:** 1

## Configuration

No configuration variables are required.
