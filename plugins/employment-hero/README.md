# Employment Hero

Access Employment Hero HR & payroll data via the myHub-hosted OAuth MCP gateway. Browser OAuth — no env vars, no keys.

**Tools available:** employees, leave requests, leave balances, timesheets, teams, locations, pay schedules, and pay details.

## Configuration

Connect via OAuth — click **Connect** in the myHub workspace and authorise access through the Employment Hero login page. No API keys required.

## Widgets

| Widget | Description |
|---|---|
| Pending Leave Requests | Live list of pending employee leave requests with employee name, date range, and leave type |
