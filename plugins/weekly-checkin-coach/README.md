# Weekly Check-in Coach

Collects a short weekly check-in from each team member, logs it, turns blockers into WorkQ items for the manager, and posts a Friday summary. Works only inside Workspace — no connectors.

Packaged from a MyHub workspace via the /developer Plugins page.

## What's in the box

- **Automations:** Monday check-in nudge (installed as Draft — publish in the installing workspace)
- **Activity templates:** Blocker raised
- **Form templates:** Weekly check-in
- **Forms:** Weekly check-in
- **Custom tables:** Check-ins (review and publish during extension setup)
- **Setup:** Weekly Check-in Coach setup (each person reviews their configuration and account bindings)
- **Processes:** Weekly check-in cycle
- **Capabilities:** Post the weekly summary to the team, Raise a blocker for the manager, Read check-ins, Update a check-in's status
- **Agent views:** Setup pages
- **Skills:** 2

## Configuration

No configuration variables are required.
