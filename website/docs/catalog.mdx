# Plugin catalog

Every plugin currently shipping in the marketplace. Filter by category, click through to the source on GitHub.

<PluginCatalog />

## Installing a plugin

```bash
/plugin marketplace add mySMB-AI-Studio/mysmb-marketplace
/plugin install <plugin-name>
```

Then set the environment variables listed in the plugin's `## Configuration` section.
