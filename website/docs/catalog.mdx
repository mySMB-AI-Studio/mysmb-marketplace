# Plugin catalog

Every plugin currently shipping in the marketplace. Filter by category, click through to the source on GitHub.

<PluginCatalog />

## Installing a plugin

```bash
/plugin marketplace add mySMB-AI-Studio/mysmb-marketplace
/plugin install <plugin-name>
```

Then set the environment variables listed in the plugin's `## Configuration` section.

## Categories

Use the category filter on the table above to browse by area (accounting, payroll, HR, CRM, productivity, and more). The table is generated directly from `.claude-plugin/marketplace.json`, so it always reflects exactly what's shipping — it's the source of truth for the plugin list.
